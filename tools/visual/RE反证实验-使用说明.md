## 步骤 2：做 A/B/C/D 四组对照实验

打开任一多模态前端（Claude.ai / ChatGPT / Gemini，**不是** VS Code 里的 Copilot），按下表跑 4 组对话。**任务统一用 #2**（平面图上改动一堵墙后，立面图怎么跟着顺改）。

| 组 | 输入 | 评估的问题 |
|----|------|-----------|
| **A. 单结构** | 平面图的 `scan_report.json` 摘要（房间数/墙/门窗统计） + 任务 #2 | 仅看 JSON，VLM 能否说出立面图该改什么？ |
| **B. 单视觉（V1）** | `v1_overview_plan.png` + 任务 #2 | 只看平面图，VLM 能否推断立面图？ |
| **C. 视觉+视觉（V3）** | `v3_plan_vs_elevation.png`（平面+立面并排）+ 任务 #2 | 看两张图，VLM 能否指认对应关系？ |
| **D. 结构+视觉（双视角）** | 平面 JSON + `v3_plan_vs_elevation.png` + 任务 #2 | 双通道，效果最好？ |

### 统一提示词模板（贴到前端用）

```
你是一个 CAD 工程师。我有一份住宅装修图（平面图和立面图）。

[组 A：贴 JSON 摘要]
[组 B：上传 v1_overview_plan.png]
[组 C：上传 v3_plan_vs_elevation.png]
[组 D：贴 JSON + 上传 v3_plan_vs_elevation.png]

任务：现在要在平面图上把一堵墙移动 500mm。
请回答三个问题：
1. 立面图上哪一段/哪条线对应平面图上这堵墙？（关联指认）
2. 墙移动后，立面图上哪些元素应该跟着改？（改动推演）
3. 给出可行的顺改步骤，编号列出。（方案可行性）
```

## 步骤 3：评分判据

每个子问题 0-3 分：

| 分数 | 标准 |
|------|------|
| **0** | 完全瞎答 / 答非所问 |
| **1** | 答了一部分但有关键错误 |
| **2** | 基本对，有遗漏或小错 |
| **3** | 完整准确，符合 CAD 工程逻辑 |

**总分（9 分满分）判据**：

- **D 组（双视角）≥ A 组 + 3 分** → 方案 G **成立**，进 Phase G-1
- **D 组 ≈ A 组（差 ≤ 1 分）** → 方案 G **作废**，省下工程投入，继续纯结构路线
- **C 组 >> D 组** → 说明结构数据干扰了视觉判断，方案 G 要调整（视觉为主、结构为辅）
- **A 组也很高** → 任务本身不依赖视觉（结构 JSON 就够），方案 G 对这份样本边际价值低，需要换更复杂的任务（如 #6 材料表）重测
