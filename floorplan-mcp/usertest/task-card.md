## 任务书（按顺序做）

### T1 — 安装起步（15 分钟目标）

**目标**：让 floorplan 工具在你的客户端里能调起来。

主持人会给你：
- 容器已经 `docker compose up -d` 起好
- Docker Desktop 在跑
- ODA File Converter 已挂载

**你做**：
1. 打开客户端（Goose 或 OpenWork 之一，主持人指定）
2. 按 `clients/goose.md` 或 `clients/openwork.md` 配 floorplan 工具
3. 跟客户端说一句话，确认 floorplan 工具被调起来

**什么时候算 T1 完成**：客户端能识别到 floorplan 工具（如 Goose 显示 `Connected to extension floorplan` 或调一次工具没报错）。

> 卡住 5 分钟以上主持人会给提示（**每给一次提示请主持人在 scorecard 上记一笔**）。

**完成情况**（主持填）：☐ 完成 / ☐ 给提示完成 / ☐ 失败 / 用时：___ 分钟

---

### T2 — 读图理解

**你做**：把你自己带来的那张 DWG 放到 `~/dwgs/`，然后告诉客户端：

> "看一下 ~/dwgs/[你的文件名].dwg 这张图"

**你期望看到什么**：户型统计（房间数 / 家具数 / 门窗数）+ 一张渲染的预览图。

**完成后**：在 CAD viewer 里打开原图核对客户端说的数对不对。

| 客户端说 | 真实（你核对后） | 对吗 |
|---------|----------------|-----|
| 房间数：___ | ___ | ☐ 对 / ☐ 错 |
| 家具数：___ | ___ | ☐ 对 / ☐ 错 |
| 门窗数：___ | ___ | ☐ 对 / ☐ 错 |
| PNG 出现了？ | ☐ 是 / ☐ 否（在哪也找不到） | |

**完成情况**：☐ 完成 / ☐ 部分对 / ☐ 失败

### T3 — 查询面积

**你做**：问一句

> "客厅面积多大？"

**期望**：客户端答出具体数字，与你手算或原图标注的对比。

| 客户端答客厅面积 | 你核对的真值 | 误差 | 可接受 |
|-----------------|------------|-----|-------|
| ___ ㎡ | ___ ㎡ | ___% | ☐ 是 / ☐ 否 |

**完成情况**：☐ 完成准确 / ☐ 完成有误差 / ☐ 失败

### T4 — 查询家具

**你做**：问一句

> "客厅里有哪些家具？"

**期望**：列出家具清单。

| 客户端列出 | 你原图核对的 | 一致吗 |
|-----------|------------|-------|
| ___ | ___ | ☐ 完全一致 / ☐ 多了 / ___ / ☐ 少了 / ___ |

**完成情况**：☐ 完全一致 / ☐ 基本一致（80%+）/ ☐ 偏差大 / ☐ 失败

---

### T5 — 改 + 撤销（⚠️ 核心任务）

**你做**：用自己的话说一句修改请求，比如：

> "把客厅沙发往右移 500 毫米" / "把那个门挪一点"

**期望**：客户端告诉你"已移动"+ 给你一张改后的图。

**关键检查**：
1. 改完后看 PNG，**改对了吗**？
2. 客户端有没有告诉你**备份文件**在哪？
3. 你说"撤销刚才那个改动"，能不能回滚到改之前的状态？

| 检查 | 结果 |
|------|-----|
| 修改方向/距离对吗 | ☐ 完全对 / ☐ 有偏差 / ☐ 完全错 |
| 备份条目出现且能找到 | ☐ 是 / ☐ 否 |
| 撤销能成功回滚 | ☐ 是 / ☐ 否 / ☐ 没敢试 |
| 改坏了什么吗 | ☐ 没有 / ☐ 有：___ |

> ⚠️ 如果"改坏了什么"，立即在 scorecard 标"修改正确率失败"，本次测试按红线失败处理。

**完成情况**：☐ 完全成功（改对+能撤销）/ ☐ 部分成功 / ☐ 失败

### T6 — 自由探索（最重要）

**你做**：花 8 分钟，**问它任何你想问的、或让它做任何你想做的**。

例子（不用照做）：
