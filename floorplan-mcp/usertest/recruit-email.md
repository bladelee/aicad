# 招募邮件模板 — V3 真人测试

> 给 P1（室内设计师）/ P2（装修施工）/ P3（懂 DIY 的房主）三画像各一版。
> 复制 → 改 [名字] → 发送。报酬/时间/orientation 与 `usertest/README.md §0` 一致。
>
> 招够 **≥2 P1 + 1 P2 = 3 人** 即可启动；更多看精力。
> 排除标准：写过 Python / 用过 Claude Code/Cursor 的不要（详见 `usertest/README.md §0.2`）。

## 模板 A：给室内设计师（P1，主画像，要 ≥2）

**标题**：帮我测个 AI 改图工具？30-45 分钟 / 一杯咖啡钱

你好 [名字]，

最近在做一个工具：**让设计师用聊天的方式读/查/改装修 DWG 图**——比如打字说"看一下这张图"、"客厅面积多大"、"把沙发右移 500mm"，就让 AI 直接改。想请你这种一线设计师来试一下，帮我看看哪些地方好、哪些地方坑。

**对你的好处**：
- 30-45 分钟看个新东西，对 AI 工具现状第一手感受
- 50 元咖啡券（或等值）
- 如果觉得有用，可以作为你后续免费试用的内测用户

**需要你**：
- 这次测试**带一张你做过、可以用的装修 DWG**（建议非敏感的 60-100㎡ 户型）
- 在我们约好的时间，远程共享屏幕（或现场），按我给的任务书操作
- **完全不用懂技术**——我装好环境，你只要打字说话就行

**你不需要做的**：
- 不用懂 Python / 编程
- 不用装什么——客户端我帮你配好
- 测试**不会答错**——任何问题都是工具的问题不是你的问题

时间约 [建议日期 1] 或 [建议日期 2]，怎么样？

如果太忙也没事，下次有更新再约。如果身边有也做室内设计的同事愿意来试，欢迎拉来一起。☕

谢谢！

[你的名字]

## 模板 B：给装修施工 / 包工头（P2，要 ≥1）

**标题**：能用 CAD 看图的朋友帮个忙——测个 AI 改图工具，30-45 分钟

[名字] 老师，

最近在搞个东西：**用聊天的方式操作 CAD 改图**。比如不用记快捷键、不用切软件，打字说"这张图有多少个门""家具摆对没"就让 AI 答——想请你这种常看 CAD 图的人帮测测实际好不好用。

**简单背景**：
- 我已经把工具装好了，你只要按我的步骤打几句话就行
- 30-45 分钟，给你 50 元红包或咖啡
- 远程 / 现场都行

**要你带的**：
- 你手头一张**可以用的施工 DWG**（量房图 / 平面图都行，非敏感的）
- 几个你平时常想问图的问题（比如"这段墙多长""主卧开门位置对不对"）

**你不用**：写代码、装软件、记命令。所有问题都好——不爽就骂工具，不会答错。

时间 [日期 1] / [日期 2]，方便哪个？

[你的名字]

## 模板 C：给懂 DIY 的房主（P3，可选 0-1）

**标题**：想给自家房子做个"AI 改图"的小白鼠吗？（30-45 分钟，50 元咖啡）

你好 [名字]，

我做了个工具想用 AI 让普通人也能改装修图——但因为是给小白用的，更需要请你这样平时不太碰 CAD 的人帮我试。

**简单说**：
- 我装好工具，远程手把手带你打几句话，看 AI 能不能读懂你的图
- 30-45 分钟，50 元咖啡券
- 完全不用懂技术——就像跟 ChatGPT 聊天

**带**：你家户型图（设计公司给你的 DWG 最好；PDF 也可以转）。**完全不用担心损毁原图**——工具会自动备份。

时间 [日期 1] / [日期 2] OK 吗？

[你的名字]

## 招到了怎么回复（一键确认模板）

收到对方确认后，发这个确认信息（把日期/工具/前置准备好）：

> 太好了！那 [最终日期 时间]，[远程/现场]。
> 我会提前准备好环境。到时远程的话用 [腾讯会议/Zoom/...]，链接会前 10 分钟发你。
> 方便先给我你测试时要用的 DWG 吗？我提前放进去试一下能不能正常打开（不能我会告诉你换一张）。
> 谢谢哈，到时见！

## 招募冷启动建议（很难招到设计师时）

| 困境 | 兜底招法 |
|------|---------|
| 不认识设计师 | 设计公司朋友介绍 → 朋友圈发招募 → 小红书/B站发个 demo 短视频吸引 |
| 设计师嫌陌生不愿测 | 让中间人引荐 + 测试后给内测账号 + 测试问题列表提前看降低焦虑 |
| 测试前端（Goose/OpenWork）装不起来 | 主持人**远程代装**（用向日葵/Todesk 接管装好）—— 别让对方折腾环境 |
| 报酬不好意思给朋友 | 改成请你吃饭 / 给孩子寄个小礼物，或募集成"新产品共创官"创意 |

> 真人测试 ≠ 形式化。3 个真设计师真实的半小时，强过 100 份线上问卷。
