# 装修 AI CAD — 种子设计师上手指南（一页纸）

> 版本 v0.3.0 · 适用人群：首批试用设计师 · 预计耗时 **15 分钟**
> 任何问题看最后一节"卡住了怎么办"

---

## 你能得到什么

在 Goose 聊天框里说人话改装修图，例如：

> "把 E6037 那堵墙向右移 500mm，尺寸标注跟着更新"
> "把图里所有 ST-01 材料编号换成 ST-A"

AI 自动改图 → 秒回改好的 DXF → 你在 AutoCAD 里打开检查、手工精修。
**AutoCAD 照常用**（本工具不取代它，只干批量改图的脏活）。

---

## 第 1 步：装 Goose（5 分钟）

1. 下载 Goose Desktop：`https://github.com/aaif-goose/goose`（Releases 页选你的系统）
2. 首次启动选 LLM provider——二选一：
   - **有 Anthropic/OpenAI key**：直接填（效果好）
   - **不想花钱**：装 Ollama（`https://ollama.com`）+ 拉一个 qwen 模型，Goose 里选 Ollama

## 第 2 步：拿两样东西（问 IT / 供应商要）

| 东西 | 干什么用 | 样子 |
|------|---------|------|
| **服务器地址** | AI CAD 服务跑在公司服务器上 | `http://10.x.x.x:3000/sse` |
| **你的 token** | 你的通行证（勿转发他人） | 一串随机字符，如 `3f9a...` |

## 第 3 步：配置 Goose（2 分钟）

Goose → Settings → Extensions → **Add MCP Server** → 选 Advanced / Edit JSON，粘贴（**替换两处尖括号内容**）：

```json
{
  "mcpServers": {
    "floorplan": {
      "type": "remote",
      "url": "http://<服务器地址>:3000/sse",
      "headers": {
        "Authorization": "Bearer <你的token>"
      }
    }
  }
}
```

保存 → 重启 Goose → 扩展列表出现 `floorplan` 即成功。

## 第 4 步：验证（1 分钟）

聊天框输入：

> 列一下可用的装修工具

应看到 `user_move_wall`、`user_rename_material` 等 11 个工具的说明。

再来一句真格的：

> 看看 /data/test-apartment.dxf 有什么

返回图层/墙体/房间统计 = 全通 ✅

## 日常怎么用（口语 → 工具对照）

| 你说 | AI 会调 | 产出 |
|------|---------|------|
| "把 X 墙右移 500" | user_move_wall | `<原图>_moved.dxf` |
| "移墙并把标注一起改" | user_move_wall_with_dim | `<原图>_with_dim.dxf` |
| "墙挪了地坪天花跟着动" | user_move_wall_with_floor_ceil | `<原图>_fc.dxf` |
| "ST-01 全换成 ST-A"（先说"先看看有几处"= 不落盘预览）| user_rename_material | `<原图>_ST-01_to_ST-A.dxf` |
| "确认都改干净了吗" | user_verify_rename | 校验报告 |
| "这堵墙边上有哪些标注" | user_probe_dimensions | 标注清单 |

**文件在哪**：改后的图都在服务器 `~/dwgs/`（你们的共享盘）；原始图**永不修改**（每次都产新文件）。

**进 AutoCAD**：从共享盘拿改后 DXF → 打开检查 → 手工精修 → 另存回 DWG。

---

## 规矩（重要）

1. ❌ 不要把 token 发给别人（一人一个）
2. ✅ 大改动前让 AI 先 dry-run（"先看看有多少处"）
3. ✅ 共享盘按项目建子目录，别把图都堆根目录
4. ❌ 不要一次改几十张图不停手——每次改完抽查一张再继续

## 卡住了怎么办

| 症状 | 大概率原因 | 快速自查 |
|------|-----------|---------|
| 连不上 / 转圈 | 服务器没起或网络不通 | 找 IT `curl http://<ip>:3000/sse` 看通不通 |
| 401 | token 错/过期 | 找 IT 重新发 |
| AI 说找不到工具 | Goose 扩展没配好 | 重做第 3 步，重启 Goose |
| 改完图打不开 | 极少见（格式问题）| 把报错截图发群里 |

**反馈渠道**：直接在群里发截图 + 你当时说的一句话，我们逐条跟。
