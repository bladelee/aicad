## 重要发现

这是**天正建筑（TArch/TWT）软件画的图**，不是纯 AutoCAD：
- 块名前缀含 `$TCHSYS$` `$TwtSys$` `$WINLIB2D$`
- 墙/门窗是天正自定义对象，转 DXF 后变成 PROXY 实体 + XData
- 处理这些实体需要额外解析 XData 才能拿到几何信息

详见 `docs/DXF扫描报告.md`。

## 命名规范

- 文件名按"序号-中文名"格式
- 不重复项目名（已在目录名里）
- `_原始备份/` 下划线前缀（目录默认排序在最后）

## 使用注意

**所有改图动作绝不能改这里**！修改前用 `tools/` 下工具把数据 copy 到 `workdir/<项目名>/` 再改。原始 dwg 永远不动，作为对照和回滚保险。
