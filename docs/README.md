## 📝 文档规范

### 命名
- 顶层状态标识：`✅ 当前权威` / `🆕 新增活文档` / `⏸️ 暂停` / `⚠️ 已取代` / `🗄️ 已归档`
- 复盘文件名：`复盘-YYYY-MM-DD-{阶段}.md`，每阶段一份不复盖
- 任务文件名：编号前缀（#1/#2/...）+ 短描述

### 互引
- 同子目录：直用文件名，例如 `产品Spec.md`
- 跨子目录：相对路径，例如 `../01-产品/产品Spec.md`
- 指向代码：相对回到根，例如 `../../tools/dxf_edit/move_wall.py`

### 何时归档
文档顶部标"⚠️ 已被取代"或"🗄️ 已归档" → 移到 `99-归档/`。
