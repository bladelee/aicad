# 装修 DWG 联动改造器 — 产品部署/安装/使用手册

> **版本**：v0.1 (MVP)
> **更新**：2026-08-16
> **目标读者**：实施工程师、客户 IT、设计师本人
> **支持平台**：**macOS 13+（Intel/Apple Silicon）、Windows 10+、Linux**

---

## 0. 产品一句话介绍

**输入**：一套装修工程 DWG 图纸（5+ 张）+ 改造需求（自然语言或参数 JSON）

**输出**：改好的 DXF 图纸（保留原图所有未改实体，仅改指定处）

**3 大已实现能力**（MVP 演示用）：
1. **材料编号联动**：ST-01 → ST-A 等编号跨 3 张图同步替换
2. **改墙 + 同步填充**：平面图改一堵墙，自动联动同图填充图层
3. **改墙 + 同图地坪/天花顺改**：改墙位置附近的地坪分缝线/天花造型线/灯具等同步平移

## 1. 系统要求

### 1.1 客户端（设计师本机）

| 项 | 要求 | 备注 |
|---|---|---|
| 操作系统 | macOS 13+ / Windows 10+ / Linux | 三平台都支持 |
| 内存 | ≥ 8 GB（处理大 DXF 16MB+ 建议 16GB） | 处理 22MB 立面图时需 1-2GB 瞬时内存 |
| 磁盘 | ≥ 10 GB 可用 | Docker 镜像共 4.5GB + 转换产物 |
| Docker | **必装** Docker Desktop 4.30+ | 见 §2 |
| CAD 软件 | 任意支持 DXF 的（AutoCAD/中望/浩辰/天正）| 仅用 DXF 格式互通 |

### 1.2 服务端（可选，远程模式）

如走远程模式（多人共用算力），需要 Linux 服务器（4 核 / 8GB / 50GB），装 Docker + 我们的镜像即可。**MVP 阶段建议先走客户端模式**。

## 2. 客户安装步骤（10 分钟）

### Step 1. 装 Docker Desktop（如果已有可跳过）

**macOS**:
1. 访问 https://www.docker.com/products/docker-desktop/ 下载对应芯片版本
2. 拖到 Applications，启动后等鲸鱼图标变绿

**Windows**:
1. 同上下载 Docker Desktop for Windows
2. 安装时勾选 "Use WSL 2 instead of Hyper-V"
3. 重启后等启动完成

**验证**:
```bash
docker --version                  # 应有 Docker version 27+
docker run --rm hello-world       # 应看到 "Hello from Docker!"
```

### Step 2. 拷贝产品包

将我们交付的目录拷到本机任一位置（建议 `~/floorplan-processor/`）：

```
floorplan-processor/
├── README.md                  # 本文件
├── samples/                   # 原始 DWG（设计师把要改的图放这里）
├── workdir/                   # 程序生成的 DXF 在这里（自动创建）
├── tools/                     # 工具脚本（不要改）
├── ops/                       # 运维文档
└── floorplan-mcp/             # 主服务代码（不要改）
```

> **如果你是通过 git clone 获取本项目**（而不是拿到 tar 交付包）：
> 本仓库的 `samples/` 下的 DWG/PDF 原图走 **Git LFS**，clone 前请先安装并启用 LFS，否则拉到的只是几百字节的指针文件，无法直接使用：
> ```bash
> # 一次性安装（任选其一）
> brew install git-lfs          # macOS
> # winget install GitHub.GitLFS # Windows
> git lfs install               # 启用（每台机器一次）
>
> git clone <仓库地址>           # 然后 clone，LFS 大文件会自动下载
> # 若已 clone 过才发现拉的是指针：cd 进仓库后跑 git lfs pull
> ```

### Step 3. 加载 Docker 镜像（无需联网）

```bash
cd ~/floorplan-processor
# 加载我们交付的镜像 tar 包（约 4.5GB，加载需 5 分钟）
docker load -i images/libredwg-cli.tar
docker load -i images/floorplan-mcp.tar

# 验证镜像就位
docker images | grep -E "libredwg|floorplan"
# 应看到 libredwg-cli 和 floorplan-mcp 两行
```

### Step 4. 准备图纸

把要处理的 DWG 文件放进 `samples/<项目名>/`：

```bash
mkdir -p samples/我的项目
cp /path/to/客户图纸/*.dwg samples/我的项目/
```

## 3. 日常使用流程（设计师 5 步走）

### 流程 A：DWG → DXF 转换（每个项目首次 1 次）

```bash
cd ~/floorplan-processor

# 一键转换所有 DWG 到 DXF
bash tools/dwg_to_dxf/convert_dwg.sh samples/我的项目 workdir/我的项目/dxf
```

输出：`workdir/我的项目/dxf/*.dxf`（可直接用 CAD 软件打开验证）

### 流程 B：执行改造任务

#### B1. 材料编号联动替换

```bash
# 用法：OLD_CODE=旧编号 NEW_CODE=新编号
docker run --rm -v "$PWD:/data" \
    -e PYTHONHOME=/opt/FreeCAD/usr \
    -e LD_LIBRARY_PATH=/opt/FreeCAD/usr/lib \
    -e SSL_CERT_FILE=/opt/FreeCAD/usr/ssl/cacert.pem \
    -e OLD_CODE=ST-01 -e NEW_CODE=ST-A -e DRY_RUN=0 \
    --entrypoint=/bin/bash \
    floorplan-mcp:latest \
    -lc "/opt/FreeCAD/usr/bin/python /data/tools/dxf_edit/apply_material_rename.py"
```

**先看不改的"预览"模式**：`-e DRY_RUN=1` 只统计改多少处，不写文件。

#### B2. 改一堵墙

```bash
# 用法：DX=横移量(mm) WALL_HANDLE=墙的 handle 号
docker run --rm -v "$PWD:/data" \
    -e PYTHONHOME=/opt/FreeCAD/usr \
    -e LD_LIBRARY_PATH=/opt/FreeCAD/usr/lib \
    -e SSL_CERT_FILE=/opt/FreeCAD/usr/ssl/cacert.pem \
    -e WALL_HANDLE=E6037 -e DX=500 -e OUTPUT_SUFFIX=_改墙 \
    --entrypoint=/bin/bash \
    floorplan-mcp:latest \
    -lc "/opt/FreeCAD/usr/bin/python /data/tools/dxf_edit/move_wall.py"
```

其中 `WALL_HANDLE` 可通过 CAD 软件 "特性"面板查到，或运行我们提供的探查工具：
```bash
# 列出前 20 条墙的 handle 和坐标
docker run --rm -v "$PWD:/data" -e PYTHONHOME=/opt/FreeCAD/usr -e LD_LIBRARY_PATH=/opt/FreeCAD/usr/lib -e SSL_CERT_FILE=/opt/FreeCAD/usr/ssl/cacert.pem --entrypoint=/bin/bash floorplan-mcp:latest -lc "/opt/FreeCAD/usr/bin/python /data/tools/dxf_scan/probe_layer_bbox.py"
```

#### B3. 改墙后地坪天花同步（自动联动）

```bash
# 用法：在 B2 基础上加 NEAR 半径范围（默认 2000mm）
docker run --rm -v "$PWD:/data" \
    -e PYTHONHOME=/opt/FreeCAD/usr \
    -e LD_LIBRARY_PATH=/opt/FreeCAD/usr/lib \
    -e SSL_CERT_FILE=/opt/FreeCAD/usr/ssl/cacert.pem \
    -e WALL_IDX=6 -e DX=500 -e NEAR=2000 \
    --entrypoint=/bin/bash \
    floorplan-mcp:latest \
    -lc "/opt/FreeCAD/usr/bin/python /data/tools/dxf_edit/move_wall_with_floor_ceil.py"
```

### 流程 C：拿改后 DXF 进 CAD 校对

1. 用 CAD 软件（AutoCAD / 中望 / 浩辰）打开 `workdir/我的项目/dxf/<文件名>_改墙.dxf`
2. 检查改造效果
3. 如满意，CAD 里另存为 DWG（如客户原格式是 DWG）

## 5. 备份与回滚（产品级保险）

### 5.1 自动备份机制

**所有写操作都自动备份**：
- 材料编号替换：备份到 `<原文件>.bak_ST.dxf`
- 改墙：备份到 `workdir/19-102/backups/move_wall/<原文件>.bak1.dxf`（自动轮转 .bak1/.bak2/...）
- 改墙+地坪天花：备份到 `backups/wall_floor_ceil/`

### 5.2 手动回滚

```bash
# 用备份恢复原文件
cp workdir/19-102/backups/move_wall/3-19-102平面系统图.bak1.dxf \
   workdir/19-102/dxf/3-19-102平面系统图.dxf
```

### 5.3 原始 DWG 永不改

**重要**：`samples/` 下的 DWG 文件**永远不会被修改**。所有改动都发生在 `workdir/` 下的 DXF 文件。

## 6. 常见问题（FAQ）

### Q1: 我装不上 Docker Desktop，怎么办？
**A1**: macOS 12 及以下用户请装 Docker Desktop 4.35.0（不要装最新版，最新版需 macOS 13+）。下载链接见 `ops/docker-desktop-install.md`。

### Q2: 转换 DWG 报 Warning（"Unknown object, skipping eed/reactors/xdic"）怎么办？
**A2**: 这是正常的，libredwg 转换天正图纸时跳过扩展数据字典，**不影响几何实体**。 详情见 `ops/docker-troubleshooting.md`。

### Q3: 改完的 DXF 在 AutoCAD 里打开某些 3D 实体不见了？
**A3**: 这是 ezdxf 1.4.4 的已知限制——3D REGION 实体（ACIS 边界表示）写回时会丢失。**2D 业务（墙/门/标注）完全不受影响**。如果你需要保留 3D，请联系我们用 Phase 3 的 IFC 工作流。

### Q4: 命令太长记不住怎么办？
**A4**: 我们提供简化别名（建议加到 `~/.bashrc` 或 `~/.zshrc`）：

```bash
# 短别名（加载到 shell 后用：fp-convert / fp-move-wall / fp-demo）
alias fp-base='docker run --rm -v "$PWD:/data" -e PYTHONHOME=/opt/FreeCAD/usr -e LD_LIBRARY_PATH=/opt/FreeCAD/usr/lib -e SSL_CERT_FILE=/opt/FreeCAD/usr/ssl/cacert.pem --entrypoint=/bin/bash floorplan-mcp:latest -lc'
alias fp-convert='bash tools/dwg_to_dxf/convert_dwg.sh'
alias fp-demo='fp-base "/opt/FreeCAD/usr/bin/python /data/tools/demo_full_story.py"'
alias fp-st='fp-base "/opt/FreeCAD/usr/bin/python /data/tools/dxf_edit/apply_material_rename.py"'
alias fp-wall='fp-base "/opt/FreeCAD/usr/bin/python /data/tools/dxf_edit/move_wall.py"'
```

### Q5: 我的公司有多人需要用怎么办？
**A5**: MVP 阶段每台机器独立跑。如要多人共享，Phase 2 可部署成 Web 服务（远程模式），我们提供 API。

## 7. 开发者扩展指南（如客户想自己加任务）

### 7.1 加新的字符串替换任务（最简）

参考 `tools/dxf_edit/apply_material_rename.py`，把 `OLD_CODE`/`NEW_CODE` 改成你的目标（如 `J-01 → J-A` 家具编号），环境变量传入即可。

### 7.2 加新的几何变换任务

参考 `tools/dxf_edit/move_wall_with_floor_ceil.py` 的结构：
1. 用 `ezdxf.readfile()` 读老 DXF
2. 用 `shift_layer_entities(msp, layer, dx, dy)` 做平移（已有通用函数）
3. 用 `safe_saveas(doc, path)` 写回（**必须用这个，绕开 ezdxf 1.4.4 materials bug**）
4. 用 `backup_with_rotate(src, backup_dir)` 自动备份

### 7.3 加新的探查任务

参考 `tools/dxf_scan/probe_*.py` 系列（10 个独立脚本均可独立运行）。
