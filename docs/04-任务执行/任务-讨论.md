# DWG 读取方案讨论（开工前请拍板）

> 创建：2026-08-09
> 状态：**等用户决策**

## 0. 为什么要先决这件事

你给的 5 张图纸**全是 .dwg**，但我们的容器化 backend（ezdxf）只能读 .dxf。10 项联动改造任务**全部依赖**能先把 DWG 读进来才能开工。

## 1. 已实测的（容器内）

| 方案 | 状态 | 说明 |
|------|------|------|
| ezdxf 直接读 DWG | ❌ 失败 | 开源 ezdxf 1.4.4 不含 ODA SDK，要 `ezdxf_acc`（商业包） |
| FreeCAD `importDWG.convertToDxf()` | ❌ 静默失败 | FreeCAD 1.0.2 模块在，但底层 converter 都没装 |
| FreeCAD 的 3 个转换器探测 (`get_libredwg_converter` / `get_qcad_converter` / `get_oda_converter`) | ❌ 全返回 None | 容器里没有任何 converter |
| Homebrew `brew install libredwg` | ❌ 失败 | 本机 brew 因 Xcode 残留损坏，formula resolve 报错 |
| Ubuntu 22.04 `apt install libredwg-tools` | ❌ 失败 | 官方源不含此包 |

## 2. 剩余的可行路线（按推荐度）

### A. **装 ODA File Converter 到本机**（强烈推荐 ✅）

- **理由**：业界事实标准，保真度最高，FreeCAD importDWG 默认就是用它
- **缺点**：要你自己去官网注册下载，接受 EULA（个人/教学免费，商业要看条款）
- **步骤**：
  1. 去 https://www.opendesign.com/guestfiles/oda_file_converter 注册账号
  2. 选 "macOS" 下载 `.dmg`
  3. 装到 `/Applications/ODAFileConverter`
  4. 我帮你 docker-compose.yml 挂载好，10 分钟内能开工

### B. **在 Dockerfile 里增加 libredwg 编译**（中等推荐）

- **理由**：完全开源免 EULA，从头解决问题
- **缺点**：libredwg 没官方 apt 包，要从 PPA 或源码编译，Dockerfile 增 ~10 分钟构建
- **保真度**：略低于 ODA，特别对 AutoCAD 2018+ 格式（DWG R2018）的某些实体（如动态块、MTEXT 高级属性）可能丢字段
- **你的图纸风险**：5 张 DWG 不知道是什么版本 AutoCAD 出的，要先验证

### C. **你本机用 AutoCAD / 浩辰 / 中望 等专业 CAD 把 5 张 DWG 全部另存为 DXF**（最快 ✅✅）

- **理由**：如果你本机有任一 CAD 软件，5 分钟搞定，无需装任何东西
- **优点**：保真度 100%，立刻能开工
- **缺点**：只解决眼前 5 张，用户验证时（产品 Spec 的"普通装修师傅端"）这个动作还得再做一次

### D. **本机 Xcode 损坏先修，再用 brew 装 libredwg**（绕远路）

- **理由**：本机很多其他东西也需要 Xcode
- **缺点**：跟当前项目无关，时间投入大

## 3. 我的推荐（按综合得分）

| 顺序 | 方案 | 时间投入 | 长期价值 |
|------|------|---------|---------|
| ⭐⭐⭐ 1 | C - 用 CAD 软件另存 DXF | 你 5-10 分钟 | 中（一次性） |
| ⭐⭐ 2 | A - 装 ODA File Converter | 你 15-30 分钟 | 高（长期用） |
| ⭐ 3 | B - 容器内编译 libredwg | 我 1-2 小时 | 高（永久免 EULA） |
| ❌ 4 | D - 修 Xcode 再装 | 1-2 小时 | 不只服务于本项目 |
