## Q2: 跨视图坐标对应（#4/#5/#9 难点）

实测 3 张图的坐标差异：

| 图 | 墙线/外墙 X 跨度 | Y 跨度 | 说明 |
|----|----:|----:|------|
| 3-平面 | 大约 429000 | 小 | X 主轴展开 |
| 4-立面 | 大约 494000 | 小 | 墙线条长度跨大 |
| 5-节点 | 分散 | 分散 | 不同节点在不同区域 |

**❓ 请确认**：
- (a) 平面图的某段墙（如 handle=E6037），如何对应 4-立面图里的某根线？
- (b) 你设计时是怎么保证跨图一致的？**用人工记忆**还是**有索引块编码**？

**实测**：3-平面 有 `Z立面索引`(166 个 INSERT) 和 `Z节点索引`(69 个 INSERT) 等图层。

- (c) 这些"索引"是不是就是关联指针？里面带的属性可能是"对应哪个立面/节点"？

**✅ 实测确认（2026-08-09 04:40）**：**`Z节点索引` 块带跨图编号属性！**

```
3-平面里 Z节点索引 INSERT 的属性：
  attrib '1EA-07' = 'DE-02'   ← 节点编号 DE-02
  attrib '1EA-07' = 'DE-03'   ← 节点编号 DE-03
  attrib '1EA-07' = 'DE-08'   ← 节点编号 DE-08
  attrib '1EA-07' = 'FU-03'   ← 家具/立面 FU-03
  attrib '1EA-07' = '1EA-09'  ← 立面 1EA-09
```

这意味着：
- **平面图某墙位置 → 通过 `Z节点索引` 块的 insert 点 + 编号 → 找到 5-节点里的对应节点编号**
- 然后到 5-节点里找含 `DE-02`/`DE-03` 等编号的实体（应该是建筑编号、图纸图号字段）

→ **跨图联动有显式指针可用，不需要坐标近似匹配**。

- (d) 4-立面 / 5-节点 里有相应的"反向指针"吗？（探查中）

## Q3: "完全匹配"和"对应更新"具体含义

### #3 改墙引起其他墙体尺寸变化要"完全匹配"
- 例子：客厅西墙往南移 500mm → 东墙的标注也要改成新距离？
- 还是：A 墙移了 → B 墙自动跟着移？

### #4/#5 改 A 引起其他视图"对应更新"
- 例子：平面图的 A 墙移了 → 立面图里那面墙的立面也要画新位置/新尺寸
- 还是：立面图整段重新基于新平面重新生成？

**❓ 请确认**：

- (a) **"完全匹配"**是指**标注/尺寸数字**与几何位置完全一致（如 DIMENSION text 跟着变）？
- (b) **"对应更新"**是指**复制几何元素到对方视图**？还是**只更新对方视图里"对应"的那段**？
