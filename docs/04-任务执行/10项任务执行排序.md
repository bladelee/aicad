## 1. 评估维度

4 个评估维度的含义：

| 维度 | 评分 1-5（5=最容易/最简） |
|------|---|
| **正交性** | 不依赖其他任务，可独立完成 → 5；依赖前置 → 1 |
| **数据齐全度** | 当前数据直接能做 → 5；缺样本/字段 → 1 |
| **算法难度** | 简单字符串/坐标替换 → 5；几何推理/标注重算 → 1 |
| **现有基础** | 已有类似代码/demo → 5；全新 → 1 |

## 4. 执行计划（按排序推进，每项独立成 user_tool）

### Step 1: 完成 #6 ST-01 → ST-A（最简）

**算法**：扫 `INSERT.attribs`，tag 或 value 含 `ST-01` 的全替换为 `ST-A`，跨 3 张图同步。

- 输出：3 张新 DXF（`*_ST-A.dxf`），含备份
- 验证：扫改前/改后，确认 ST-01=0 / ST-A=357

- `move_wall(dxf_path, wall_handle, dx, dy)` 接口

**输出**: `tools/dxf_edit/move_wall.py` + `tools/dxf_edit/__init__.py`
