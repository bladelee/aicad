## 🔍 已探查但因数据/算法复杂度跳过

### #10 门宽变更（探查后**降级**，因数据形态颠覆假设）

**原假设**: 门是 INSERT 块，xscale 控宽，改 xscale 就行。

**实测**：
| 图 | 门窗图层内的几何 | INSERT 块 |
|----|---|----|
| 3-平面 | LINE 401 + ARC 307 + LWPOLYLINE 228 + INSERT 44 | `王沧门索引块` 24 个（**门索引图例**，不是真门） |
| 4-立面 | LINE 64 + ARC 45 + LWPOLYLINE 21（**无 INSERT**） | — |
| 5-节点 | LINE 296 + LWPOLYLINE 520 + INSERT 15 | `A$C692004DA` 13 个（合页等配件）|

**结论**: **门是 LINE/ARC/LWPOLYLINE 拼出来的几何**，不是单一参数化 INSERT。改门宽 = 一组几何的边界整体缩放/平移，**复杂度等同于#9 联动**，难度从 ⭐⭐ 跳到 ⭐⭐⭐⭐。

**降级到 Phase 2**，要做需先：
1. 用空间聚类识别"哪个门由哪些几何构成"
2. 找出门的"铰链轴"和"宽边"
3. 对该组几何做变换

### #8 插入新图纸编号联动（探查后**明确数据缺口**）

**XINLU-A2 图框样板（只读模板）**：
- 项目号：`Job N0. 003-04`
- 标题字段：DRAWING TITLE / 比例 / 绘图 / 设计 / 业主签字
- 中英双语：上海天钜 / SHANGHAI XINLU

**2-材料表实际只有 2 个 INSERT**：
- `TK-A2`（A2 图框）位于 (-258, 579)
- `TSM-A1`（A1 图框）位于 (786, 36)
- 材料表本体：`OLE2FRAME` 嵌入 Excel 对象（**无文本可改**）

**1-封面 Layout1 的 427 个 TEXT 全是设计说明**（"饰面板安装/吊顶基底/施工规范..."），**没找到目录索引条目**（如 `1 → 封面`/`2 → 材料表`/`3 → 平面`）。

**结论**: **目录索引条目数据缺失**。可能位置：
- OLE2FRAME 嵌入 Excel（需要解析 OLE 对象内容）
- 或在某个未扫到的图层
- 或就是直接靠文件名编码（用户命名习惯）

**阻塞**，需要用户提供"目录页是哪一页/什么格式"。
