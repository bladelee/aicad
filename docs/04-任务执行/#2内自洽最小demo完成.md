# #2 内自洽最小可工作 demo 完成（含关键 bug 发现）

> **创建**：2026-08-09 10:00
> 关联：[`docs/技能-装修图纸自动化改造SOP.md`](../05-知识沉淀/技能-装修图纸自动化改造SOP.md) §3.1
> **意义**：用最小代价打通"内自洽"类任务的完整链路，**实测发现"附近 = 2000mm"是有效初始参数**，并暴露"墙 idx 选择"对结果的关键影响。

---

## 一、目标

实现用户 2 类联动里**内自洽**类（同文件不同图层联动）的最小可工作 demo：
- 改 3-平面 里的一条墙（dx=500 平移）
- 自动在改墙位置附近找地坪/天花图层实体跟着平移
- 自动备份 + 写新文件 + round-trip 验证

## 二、初版结果（wall_idx=0）— **联动实体 = 0** ⚠️ bug

```
目标墙: handle=98F93 位置 (57976, -943781)
附近判定半径 2000mm
联动实体数 = 0   ← 完全没联动！
```

### 2.1 根因诊断：probe_layer_bbox.py 实测

```python
# 3-平面的 3 类图层 bbox：
墙图层  X[54629, 341685]  Y[-1085137, -815993]
地坪图层 X[-1546688, 1966792] Y[-2755026, 815949]   跨度比墙大一个量级
天花图层 X[-1012332, 469930] Y[-1793279, 1919600]   跨度比墙大一个量级
```

→ **目标墙 idx=0 是异类**（在墙 bbox 内但不在实体密集区，周围 2000mm 内没有任何地坪/天花实体）。

### 2.2 找到"正确"的墙

probe_layer_bbox 扫了前 50 条墙的每条墙中点到最近地坪实体的距离：

```
墙 #0 (handle=98F93): 99999   ← 异类，孤立轴网墙
墙 #1 (handle=E6032): 425
墙 #2 (handle=E6033): 607
墙 #6 (handle=E6037): 133     ← 最近，最贴近真实业务墙
```

**49 / 50 条墙都有地坪在 2000mm 内**，只有 idx=0 异常。这说明"附近 2000mm 联动"算法是有效的，**只是 idx=0 这条墙选错了**。

## 四、关键发现

### 4.1 算法层面
- **"附近 + 整体平移"是内自洽的有效初版**：24 实体在墙周围 2000mm 范围内被识别
- **"附近"半径 2000mm 是合理经验值**（典型墙宽 ~200mm，墙周围装饰带在 500-2000mm 之内）
- **墙 idx 选择必须显式指定**，不能用 idx=0 自动选（异类墙会污染结果）

### 4.2 业务层面（用户 Q3 的算法回答）

实测印证了用户 Q3 (a) **"完全匹配"的含义**：

```
墙端点 (211902) 移到 (212402) → +500mm
墙周围的地坪分缝线 / 天花造型线 / 灯具 insert 也跟着 +500mm
```

这就是"完全匹配式联动"的**朴素实现**。

### 4.3 不足 / 改进空间（真实业务还需做的事）

| 缺陷 | 影响 | 真实做法 |
|------|------|------|
| "附近"判定是粗暴半径 | 几何上跨房间也错联动 | 用 shapely 算法：只联"被墙分隔的同一空间"内的实体 |
| 整体平移而非边界匹配 | 真实业务里墙端点延伸应触发地坪线重画 | 用几何交集算法重算地坪边界 |
| 未联动 DIMENSION | 标注值应该改（"5700mm" → "6200mm"）| Phase 3.3（DIMENSION 重算专项）|

## 六、可复用算法模板

`probe_layer_bbox.py` 提供的"找附近有相关实体的目标物体"算法 **可广泛复用**：

```python
# 在大量同类实体（如墙）中，找出哪些"附近真有相关图层实体"
for w in walls[:50]:
    cx, cy = wall_center(w)
    min_d = min(distance(cx, cy, p) for ent in msp
                if ent.layer in RELATED_LAYERS for p in extract_points(ent))
    if min_d < NEAR_DIST:
        candidates.append(w)
```

下次遇到"目标选择"问题（如改哪扇门、改哪个家具）就用这个模板。
