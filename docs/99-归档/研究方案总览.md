# 用 Chat 操作 CAD 软件绘制/操作 DWG 文件 — 技术方案研究

> 研究日期: 2026-08-08
> 研究者: Goose AI Agent

---

## 一、总体目标

通过自然语言对话（chat）控制本机 CAD 软件或直接操作 DWG/DXF 文件，实现：
- 📐 **画图**：用自然语言描述，自动生成 2D/3D 图形
- 📄 **操作 DWG/DXF**：读取、修改、保存工程图纸
- 🔄 **双向交互**：chat → CAD 生成/修改；CAD → chat 反馈状态

## 三、六大技术方案详解

### 方案 1：FreeCAD Python 脚本自动化（⭐ 推荐）

**原理**: FreeCAD 完全由 Python 驱动，可在无 GUI 模式（headless）下运行，作为 Python 库嵌入外部应用。

**核心能力**:
- ✅ 创建 2D/3D 几何体（线、圆、弧、多边形、样条曲线、实体建模等）
- ✅ 导入/导出 DXF（通过 `importDWG` / `importDXF` 模块）
- ✅ 导入/导出 DWG（需配合 ODA File Converter 或 LibreDWG）
- ✅ 宏系统（Macro），可录制和回放操作
- ✅ 完整的 Python API（App 模块、Gui 模块、Part、Draft、Sketcher 等）

**运行模式**:

```python
# 模式 1: 命令行运行脚本 (freecadcmd)
# $ freecadcmd myscript.py

# 模式 2: 嵌入外部 Python (import FreeCAD)
import sys
sys.path.append('/Applications/FreeCAD.app/Contents/Resources/lib')
import FreeCAD
import Part

doc = FreeCAD.newDocument("my_drawing")
box = Part.makeBox(100, 50, 30)
doc.addObject("Part::Feature", "Box").Shape = box

# 导出为 DXF
import importDXF
importDXF.export(doc.Objects, "/tmp/output.dxf")

doc.recompute()
```

**DWG 支持路径**:
1. **ODA File Converter**（免费但闭源）: 将 DWG↔DXF 互转，FreeCAD 可自动调用
2. **LibreDWG**（GNU 开源）: 直接读写 DWG，FreeCAD 可集成
3. **Teigha**（商业）: ODA 的商业 SDK

**Chat 集成方式**:
```
用户: "画一个 100x50 的矩形，左下角在原点"
     ↓
LLM 生成 Python 脚本:
     import FreeCAD, Draft
     doc = FreeCAD.newDocument()
     rect = Draft.makeRectangle(100, 50)
     doc.recompute()
     importDXF.export([rect], "output.dxf")
     ↓
freecadcmd 执行脚本 → 生成 DXF/DWG 文件
     ↓
返回文件路径给用户
```

**优势**:
- 开源免费，社区活跃
- Python API 极其完整，可编程控制一切
- 支持 headless 模式，适合服务端
- 支持 2D 和 3D
- 跨平台

**劣势**:
- 安装体积大（~500MB）
- DWG 原生支持需要额外工具
- Headless 模式下某些 GUI 依赖模块不可用

**已有项目**: `ghbalf/freecad-ai` (★420) — FreeCAD AI 工作台插件，支持 OpenAI/Claude/Ollama/MCP

### 方案 2：ezdxf 直接操作 DXF 文件（⭐ 推荐 — 最简单）

**原理**: 纯 Python 库，无需任何 CAD 软件，直接创建/读取/修改 DXF 文件。

**核心能力**:
- ✅ 创建/读取/修改 DXF 文件
- ✅ 支持 DXF 版本: R12, R2000, R2004, R2007, R2010, R2013, R2018
- ✅ 支持实体: LINE, CIRCLE, ARC, TEXT, POLYLINE, LWPOLYLINE, DIMENSION, HATCH, SPLINE, ELLIPSE, INSERT (块引用) 等
- ✅ 支持图层、块、标注、填充
- ✅ 渲染: matplotlib 后端导出 PNG/PDF/SVG
- ✅ ASCII DXF 和 Binary DXF 均支持
- ❌ **不支持 DWG**（DXF 专用）

**代码示例**:
```python
import ezdxf

# 创建新 DXF 文件
doc = ezdxf.new('R2010')
msp = doc.modelspace()

# 画矩形
points = [(0, 0), (100, 0), (100, 50), (0, 50), (0, 0)]
msp.add_lwpolyline(points)

# 画圆
msp.add_circle(center=(50, 25), radius=10)

# 添加文字
msp.add_text("Hello CAD", dxfattribs={'height': 5, 'insert': (10, 60)})

# 添加标注
msp.add_linear_dim(base=(50, -10), p1=(0, 0), p2=(100, 0))

# 设置图层
doc.layers.add('CENTER_LINE', color=1)

# 保存
doc.saveas("output.dxf")

# 渲染预览
import ezdxf.addons.drawing as drawing
from ezdxf.addons.drawing.matplotlib import MatplotlibBackend
fig, ax = drawing.render(doc.modelspace(), MatplotlibBackend())
fig.savefig("preview.png")
```

**Chat 集成方式**:
```
用户: "画一个直径20的圆，圆心在(50,50)"
     ↓
LLM 直接生成 ezdxf Python 代码
     ↓
Python 执行 → 生成 DXF 文件
     ↓
渲染 PNG 预览返回给用户
```

**优势**:
- **无需安装 CAD 软件**，纯 Python 库
- 安装简单: `pip install ezdxf`
- API 清晰，LLM 容易生成正确代码
- 支持 DXF 全版本
- 可渲染预览图

**劣势**:
- 仅支持 DXF，不支持 DWG
- 仅 2D，无 3D 建模能力
- 无法与现有 DWG 文件直接交互（需先转换）

**DWG 转换方案**: 如果需要 DWG，可搭配 ODA File Converter 做 DXF→DWG 转换

### 方案 3：OpenSCAD 脚本驱动（⭐ 推荐 — LLM 最友好）

**原理**: OpenSCAD 是纯脚本驱动的 CAD，语法极简，LLM 生成准确率高。

**核心能力**:
- ✅ 纯脚本 DSL，函数式编程风格
- ✅ CSG（构造实体几何）建模
- ✅ 2D 轮廓 → DXF 导出
- ✅ 3D 模型 → STL 导出
- ✅ 命令行运行: `openscad -o output.dxf script.scad`
- ✅ WASM 支持（可浏览器运行）

**代码示例**:
```openscad
// 画一个带圆孔的矩形板
difference() {
    square([100, 50]);
    circle(r=10, center=true);
    translate([50, 25, 0])
        circle(r=5);
}
```

**Chat 集成方式**:
```
用户: "做一个 100x50 的板，中间挖一个直径10的孔"
     ↓
LLM 生成 OpenSCAD 脚本
     ↓
openscad -o output.dxf script.scad
     ↓
返回 DXF 文件
```

**已有项目**:
- `Adam-CAD/CADAM` (★4,950) — YC W25 开源 text-to-CAD Web 应用，OpenSCAD + WASM
- `zacharyfmarion/openscad-studio` (★192) — AI 辅助 OpenSCAD 编辑器
- `KrishKrosh/ScadLM` (★22) — 开源 AI Agent CAD 生成
- `format37/openscad-mcp` (★12) — OpenSCAD MCP 服务器

**优势**:
- 语法最简单，LLM 生成准确率最高
- 轻量，命令行即可运行
- 支持浏览器运行 (WASM)
- 开源免费

**劣势**:
- 2D 功能有限（主要是 2D 轮廓拉伸为 3D）
- 不支持 DWG 格式
- 无标注、图层等工程图功能
- 不是传统 CAD 的工作方式

### 方案 4：CadQuery / build123d（Python 参数化 CAD）

**原理**: 基于 OpenCASCADE (OCCT) 工业级几何内核的 Python CAD 库。

**核心能力**:
- ✅ 参数化 3D 建模（B-Rep 表示）
- ✅ 导出 STEP, STL, DXF, AMF, 3MF
- ✅ 2D 草图 + 3D 操作（拉伸、旋转、扫掠、布尔运算）
- ✅ 纯 Python，无需 GUI

**代码示例**:
```python
import cadquery as cq

# 创建带孔的板
result = (cq.Workplane("XY")
    .rect(100, 50)
    .extrude(10)
    .faces(">Z")
    .workplane()
    .hole(10))

# 导出
cq.exporters.export(result, "output.step")
cq.exporters.export(result, "output.dxf")
```

**已有项目**:
- `CadQuery/cadquery` (★5,571) — 最流行的 Python CAD 库
- `gumyr/build123d` (★2,813) — CadQuery 改进版
- `OpenOrion/CQAsk` (★185) — LLM 生成 CadQuery 代码
- `Text-to-CadQuery/Text-to-CadQuery` (★111) — 文本到 CadQuery

**优势**:
- 工业级几何内核 (OCCT)
- Python 生态，LLM 友好
- 支持 STEP 等工业格式
- 3D 建模能力强

**劣势**:
- 安装较复杂（依赖 OCCT）
- DXF 导出主要是 2D 轮廓
- 不支持 DWG

### 方案 5：MCP 协议控制 CAD 软件（⭐ 新兴趋势）

**原理**: 通过 MCP (Model Context Protocol) 服务器桥接 LLM 和 CAD 软件，实现实时交互控制。

**已有项目**:

| MCP 项目 | CAD 软件 | Stars | 特点 |
|----------|----------|-------|------|
| `ghbalf/freecad-ai` | FreeCAD | 420 | 支持 OpenAI/Claude/Ollama，FreeCAD 插件 |
| `proximile/FreeCAD-MCP` | FreeCAD | 3 | FreeCAD + AI 模型 MCP |
| `Psalmustrack/lambdacad-mcp` | AutoCAD/BricsCAD | 0 | AutoLISP MCP，100 个工具 |
| `format37/openscad-mcp` | OpenSCAD | 12 | OpenSCAD MCP 服务器 |
| `ndoo/fusion360-mcp-bridge` | Fusion 360 | 20 | Claude Code 连接 Fusion 360 |
| `NeonGlay/inventor-mcp` | Inventor | 14 | 参数化 3D 建模 MCP |
| `codeofaxel/Kiln` | OpenSCAD | 43 | 3D 打印全流程 MCP |
| `sandraschi/qcad-mcp` | QCAD Pro | 7 | 建筑 CAD MCP |

**架构**:
```
Chat (LLM) ←→ MCP Protocol ←→ MCP Server ←→ CAD Software (FreeCAD/AutoCAD)
                                      ↕
                                  DWG/DXF 文件
```

**优势**:
- 直接控制真实 CAD 软件，功能最全
- 实时交互，可查看修改结果
- 支持所有 CAD 原生功能（DWG 原生支持等）
- 标准 MCP 协议，可与 Claude/GPT 等 LLM 集成

**劣势**:
- 需要安装对应 CAD 软件
- 配置较复杂
- 大多数项目还很新，成熟度不够

### 方案 6：UI 自动化方案（截屏 + 点击控制）

**原理**: 不依赖 CAD API，通过截屏识别 UI 元素，模拟鼠标点击和键盘输入控制 CAD 软件 GUI。

**可用工具**:
- **Peekaboo**（本机已有的 computerControl 工具）: macOS UI 自动化
- **pyautogui**: Python 屏幕自动化
- **AppleScript**: macOS 应用控制

**工作流程**:
```
1. 截屏 CAD 窗口
2. AI 识别 UI 元素（菜单、按钮、输入框）
3. 模拟点击 "绘图" → "直线"
4. 在命令行输入坐标
5. 截屏确认结果
6. 保存文件
```

**优势**:
- 不需要 CAD 软件 API 支持
- 可控制任何 CAD 软件
- 可处理 GUI 交互（对话框、菜单等）

**劣势**:
- ⚠️ 速度慢，每次操作需要截屏+识别
- ⚠️ 可靠性低，UI 布局变化会导致失败
- ⚠️ 无法精确控制复杂操作
- ⚠️ 需要 CAD 软件 GUI 运行

## 五、推荐技术路线

### 场景 A：纯 2D 工程图（最常见需求）

```
Chat → LLM → ezdxf Python 代码 → DXF 文件
                                    ↓
                        (可选) ODA File Converter → DWG
```

**为什么选 ezdxf**: 无需 CAD 软件，纯 Python，API 简洁，LLM 生成准确率最高，支持图层/标注/填充等工程图功能。

### 场景 B：需要操作现有 DWG 文件

```
Chat → LLM → FreeCAD Python 脚本
                    ↓
           FreeCAD (headless) 导入 DWG
                    ↓
           修改/添加内容
                    ↓
           导出 DWG/DXF
```

**为什么选 FreeCAD**: 唯一能免费处理 DWG 的方案（配合 ODA File Converter），Python API 完整。

### 场景 C：3D 建模

```
Chat → LLM → OpenSCAD 脚本 → STL/DXF
   或 → LLM → CadQuery 代码 → STEP/STL/DXF
```

### 场景 D：实时交互控制 CAD（最强大）

```
Chat (Claude/GPT) ←MCP→ FreeCAD MCP Server ←→ FreeCAD GUI
```

**为什么选 MCP**: 可实时查看修改结果，利用 FreeCAD 全部功能，体验最好。

## 七、实施建议（分阶段落地）

### Phase 1：MVP — 用 ezdxf 实现 2D 画图（1-2天）

1. 安装独立 Python: `brew install python@3.12`
2. 安装 ezdxf: `pip3.12 install ezdxf matplotlib`
3. 构建 Chat→Python 代码→DXF 的管道
4. 添加 PNG 预览渲染

### Phase 2：DWG 支持 — 集成 FreeCAD（3-5天）

1. 安装 FreeCAD: `brew install --cask freecad`
2. 安装 ODA File Converter（DWG↔DXF 转换）
3. 构建管道: Chat → FreeCAD Python 脚本 → DWG/DXF
4. 支持 DWG 文件读取和修改

### Phase 3：实时交互 — MCP 集成（1-2周）

1. 参考 `ghbalf/freecad-ai` 或 `proximile/FreeCAD-MCP`
2. 构建 FreeCAD MCP Server
3. 实现双向交互: Chat → FreeCAD 操作 → 截图反馈 → Chat

### Phase 4：高级功能 — 3D + 多格式（持续迭代）

1. 集成 OpenSCAD 或 CadQuery 支持 3D 建模
2. 支持 STEP, STL 等格式
3. 添加版本管理和协同编辑
