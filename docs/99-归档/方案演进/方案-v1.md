## 一、需求分析

### 1.1 目标场景

| 场景 | 说明 | 示例 |
|------|------|------|
| **读取理解** | 解析现有 DWG 装修图，提取结构信息 | "这个户型有几个房间？" "客厅面积多大？" |
| **修改编辑** | 在现有 DWG 上增删改元素 | "把沙发往右移 500mm" "在卧室加一个门" |
| **新建生成** | 从零生成装修图 | "画一个 80㎡ 两室一厅的平面图" |
| **查询统计** | 统计图纸中的元素 | "图中有多少个窗户？" "列出所有家具" |
| **格式转换** | DWG 与其他格式互转 | "把 DWG 导出为 PDF" |

### 1.2 房屋装修图的 DWG 结构特点

```
DWG 文件结构（典型装修图）:
├── 图层 (Layers)
│   ├── WALL       — 墙体（LINE/LWPOLYLINE）
│   ├── DOOR       — 门（INSERT 块引用）
│   ├── WINDOW     — 窗户（INSERT 块引用）
│   ├── FURNITURE  — 家具（INSERT 块引用）
│   ├── DIMENSION  — 尺寸标注（DIMENSION 实体）
│   ├── TEXT       — 文字标注（TEXT/MTEXT）
│   ├── HATCH      — 填充（地面材质、墙面等）
│   └── AXIS       — 轴线（定位用）
├── 块定义 (Block Definitions)
│   ├── 门块（各种型号）
│   ├── 窗块
│   ├── 家具块（沙发、床、桌椅、电器...）
│   └── 卫浴洁具块
├── 模型空间 (Model Space) — 主要图形
└── 布局空间 (Layout/Paper Space) — 打印排版
```

### 1.3 核心技术挑战

1. **DWG 是闭源格式** — AutoCAD 专有，需要转换工具
2. **图层/块语义** — 需要理解图层命名和块代表的实际物体
3. **坐标系统** — 建筑图纸通常用毫米为单位，坐标原点不固定
4. **空间关系** — 需要理解墙体围合形成房间、门窗位置等拓扑关系

### 2.2 核心技术选型

| 组件 | 选型 | 理由 |
|------|------|------|
| **DWG↔DXF 转换** | LibreDWG (开源) + ODA File Converter (备选) | LibreDWG 开源免费可 brew 安装；ODA 更可靠作为备选 |
| **DXF 操作引擎** | ezdxf (Python) | 纯 Python，API 清晰，支持完整 DXF 实体，LLM 友好 |
| **预览渲染** | ezdxf + matplotlib | 直接从 DXF 渲染 PNG，无需 CAD 软件 |
| **脚本执行** | Python 3.12 | 独立安装，不依赖 Xcode |
| **LLM 集成** | Chat → 生成 Python 代码 → 执行 | 直接代码生成模式，最灵活 |

### 2.3 为什么不用其他方案？

| 方案 | 不选原因 |
|------|----------|
| FreeCAD | 500MB+，启动慢，headless 模式不稳定，杀鸡用牛刀 |
| OpenSCAD | 不支持 DWG，不支持工程图（图层/标注/块），不适合装修图 |
| CadQuery/build123d | 面向 3D 零件建模，不适合 2D 建筑平面图 |
| UI 自动化 | 需要 AutoCAD GUI 运行，速度慢，不可靠 |
| AutoCAD COM/AutoLISP | 需要安装 AutoCAD（商业软件），本机未安装 |
| MCP 控制 CAD | 同上，且成熟度不够 |

**结论：LibreDWG + ezdxf 是处理 DWG 装修图的最佳组合** — 轻量、开源、无需 CAD 软件。

## 三、DWG 支持方案详解

### 3.1 DWG ↔ DXF 转换桥

#### 方案 A：LibreDWG（首选，开源）

```bash
# 安装
brew install libredwg

# DWG → DXF
dwg2dxf input.dwg -o output.dxf

# DXF → DWG
dxf2dwg input.dxf -o output.dwg

# 查看 DWG 信息
dwgread -v input.dwg
```

**支持情况**：
- ✅ 读取 DWG: R14 ~ AutoCAD 2024 (部分版本)
- ⚠️ 写入 DWG: 支持但兼容性不如 ODA
- ✅ 完全开源 (GPL)

#### 方案 B：ODA File Converter（备选，更可靠）

```bash
# 下载安装: https://www.opendesign.com/guestfiles/oda_file_converter
# (免费但需注册，闭源)

# 使用: 批量转换整个目录
ODAFileConverter "input_dir" "output_dir" ACAD2018 DXF 0 1
# 参数: 输入目录 输出目录 目标版本 格式(DXF/DWG) 递归(0/1) 审计(0/1)
```

**支持情况**：
- ✅ 读写 DWG: R12 ~ AutoCAD 2024 (全版本)
- ✅ 行业事实标准，最可靠
- ⚠️ 闭源免费，需注册下载

#### 转换策略

```python
def dwg_to_dxf(dwg_path: str) -> str:
    """DWG → DXF，优先 LibreDWG，失败则尝试 ODA"""
    dxf_path = dwg_path.replace('.dwg', '.dxf')
    try:
        subprocess.run(['dwg2dxf', dwg_path, '-o', dxf_path], check=True)
        return dxf_path
    except (FileNotFoundError, subprocess.CalledProcessError):
        # 回退到 ODA File Converter
        return oda_convert(dwg_path, target_format='DXF')

def dxf_to_dwg(dxf_path: str) -> str:
    """DXF → DWG"""
    dwg_path = dxf_path.replace('.dxf', '.dwg')
    try:
        subprocess.run(['dxf2dwg', dxf_path, '-o', dwg_path], check=True)
        return dwg_path
    except (FileNotFoundError, subprocess.CalledProcessError):
        return oda_convert(dxf_path, target_format='DWG')
```

### 3.2 ezdxf DXF 操作引擎

#### 核心操作能力

```python
import ezdxf
from ezdxf.enums import TextEntityAlignment

doc = ezdxf.readfile("floorplan.dxf")
msp = doc.modelspace()

# ========== 读取/查询 ==========

# 遍历所有图层
for layer in doc.layers:
    print(f"图层: {layer.dxf.name}, 颜色: {layer.dxf.color}")

# 按图层查询实体
walls = msp.query('LWPOLYLINE LINE').where(dxfattribs={'layer': 'WALL'})
doors = msp.query('INSERT').where(dxfattribs={'layer': 'DOOR'})
texts = msp.query('TEXT MTEXT')

# 查询块定义
for block in doc.blocks:
    if not block.is_layout:
        print(f"块: {block.name}, 实体数: {len(block)}")

# ========== 修改 ==========

# 移动实体
from ezdxf.math import Vec3
for entity in msp.query('INSERT').where(dxfattribs={'layer': 'FURNITURE'}):
    if 'sofa' in entity.dxf.name.lower():
        entity.dxf.insert = Vec3(entity.dxf.insert.x + 500, entity.dxf.insert.y, 0)

# 修改属性
for wall in walls:
    wall.dxf.color = 3  # 改颜色

# 删除实体
for entity in list(msp.query('TEXT').where(dxfattribs={'layer': 'TEMP'})):
    msp.delete_entity(entity)

# ========== 新建 ==========

# 添加墙体
wall_points = [(0, 0), (5000, 0), (5000, 3000), (0, 3000), (0, 0)]
msp.add_lwpolyline(wall_points, dxfattribs={'layer': 'WALL', 'const_width': 240})

# 插入门块（需块已定义）
msp.add_blockref('DOOR_900', insert=(2500, 0), dxfattribs={'layer': 'DOOR', 'rotation': 90})

# 添加文字
msp.add_text("客厅", dxfattribs={'height': 300, 'insert': (2500, 1500), 'layer': 'TEXT'})

# 添加尺寸标注
msp.add_linear_dim(base=(0, -500), p1=(0, 0), p2=(5000, 0), 
                   dxfattribs={'layer': 'DIMENSION'})

# 添加填充
hatch = msp.add_hatch(color=1, dxfattribs={'layer': 'HATCH'})
hatch.paths.add_polyline_path([(100, 100), (4900, 100), (4900, 2900), (100, 2900)])

# 保存
doc.saveas("modified.dxf")
```

### 3.3 装修图语义解析

将 DXF 实体解析为结构化的建筑语义信息：

```python
class FloorPlanParser:
    """解析 DXF 装修图为结构化数据"""
    
    def __init__(self, doc):
        self.doc = doc
        self.msp = doc.modelspace()
    
    def parse(self) -> dict:
        return {
            'layers': self._parse_layers(),
            'walls': self._parse_walls(),
            'doors': self._parse_doors(),
            'windows': self._parse_windows(),
            'furniture': self._parse_furniture(),
            'dimensions': self._parse_dimensions(),
            'texts': self._parse_texts(),
            'rooms': self._detect_rooms(),  # 推断房间
            'blocks': self._parse_block_defs(),
        }
    
    def _parse_walls(self) -> list:
        """提取墙体：多段线/直线，按图层过滤"""
        walls = []
        for entity in self.msp.query('LWPOLYLINE LINE'):
            layer = entity.dxf.layer.upper()
            if any(k in layer for k in ['WALL', '墙', 'WALLS']):
                coords = self._get_coords(entity)
                walls.append({
                    'layer': entity.dxf.layer,
                    'coords': coords,
                    'length': self._calc_length(coords),
                    'thickness': getattr(entity.dxf, 'const_width', 0),
                })
        return walls
    
    def _parse_doors(self) -> list:
        """提取门：块引用，按图层或块名过滤"""
        doors = []
        for entity in self.msp.query('INSERT'):
            layer = entity.dxf.layer.upper()
            name = entity.dxf.name.upper()
            if any(k in layer or k in name for k in ['DOOR', '门', 'M_']):
                doors.append({
                    'block': entity.dxf.name,
                    'position': (entity.dxf.insert.x, entity.dxf.insert.y),
                    'rotation': entity.dxf.rotation,
                    'scale': (entity.dxf.xscale, entity.dxf.yscale),
                    'layer': entity.dxf.layer,
                })
        return doors
    
    def _parse_furniture(self) -> list:
        """提取家具：块引用"""
        furniture_keywords = ['SOFA', '沙发', 'BED', '床', 'TABLE', '桌', 'CHAIR', '椅',
                              'TV', '电视', 'FRIDGE', '冰箱', 'WASH', '洗', 'TOILET', '马桶',
                              'BATHTUB', '浴', 'KITCHEN', '厨', 'WARDROBE', '柜', 'FURNITURE', '家']
        items = []
        for entity in self.msp.query('INSERT'):
            name = entity.dxf.name.upper()
            layer = entity.dxf.layer.upper()
            if any(k in name or k in layer for k in furniture_keywords):
                items.append({
                    'type': entity.dxf.name,
                    'position': (entity.dxf.insert.x, entity.dxf.insert.y),
                    'rotation': entity.dxf.rotation,
                    'layer': entity.dxf.layer,
                })
        return items
    
    def _detect_rooms(self) -> list:
        """推断房间：从墙体闭合多段线推断"""
        rooms = []
        for wall in self._parse_walls():
            coords = wall['coords']
            if len(coords) >= 4 and self._is_closed(coords):
                area = self._calc_area(coords)
                rooms.append({
                    'boundary': coords,
                    'area': area,  # mm²
                    'area_m2': area / 1e6,  # m²
                })
        return rooms
    
    # ... 辅助方法省略
```

### 3.4 预览渲染

```python
import ezdxf.addons.drawing as drawing
from ezdxf.addons.drawing.matplotlib import MatplotlibBackend
import matplotlib.pyplot as plt

def render_dxf(dxf_path: str, output_png: str, figsize=(20, 15)):
    """渲染 DXF 为 PNG 预览图"""
    doc = ezdxf.readfile(dxf_path)
    fig = plt.figure(figsize=figsize)
    ax = fig.add_subplot(1, 1, 1)
    ctx = drawing.RenderContext(doc)
    out = drawing.properties.PropertiesSetup()
    backend = MatplotlibBackend(ax)
    drawing.frontend(ctx, out, backend)
    backend.finalize()
    fig.savefig(output_png, dpi=150, bbox_inches='tight')
    plt.close(fig)
    return output_png
```
